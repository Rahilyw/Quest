# Accessibility pass (Card E5) — Nov 20, 2026

Phase 6 slice E5 on `cursor/e5-a11y` (post-E2 big-build). Scope: every mobile screen.
Checks: geofence + mobile tests, `tsc --noEmit`, `lint:tokens` (must stay 0).

## Spec covered

| Requirement | How |
|---|---|
| 48 pt targets | Back pills, unblock, edit, action, follow-list, badge close bumped to 48×48 / minHeight 48 |
| `accessibilityLabel` + `accessibilityRole` on every Pressable | Audit + fill gaps (menus, backdrops, report sheet, city rows, legal, comments) |
| Alt text on images / stickers | `questStickerAlt` on QuestRow, Folder, FeedBubble, starter, quest detail; drawer uses `alt_text` in the Pressable label |
| Layout at 130% text | `maxFontSizeMultiplier` on type roles (title/sentence 1.3; body/name/small/micro 1.35); flexWrap / flexShrink on chips and banners |
| Reduce-motion crossfade | Celebration, XP banner, queue banner already; TabBar press + BadgeTile tip skip motion when reduced |
| Colour never the only signal | Zone map dashed stroke + player ring; category icon + label (+ selected ink border); queue count badge; XP banner flash icon + text |
